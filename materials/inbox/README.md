# Entrada para nuevo material

Agrega aquí nuevas fotos, logos o fichas de producto destinadas a ser públicas. Incluye un archivo de texto con nombre, precio, tallas, medidas y stock de cada artículo cuando estén confirmados. No incluyas la planilla financiera completa ni columnas de costos, ventas o márgenes. El sitio no lee esta carpeta automáticamente: el material se revisa antes de publicarse.
